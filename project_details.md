Dowson-Burger- Station-Excel-Dashboard- From Order to Insights

I’m delighted to share my latest project on a burger shop, built in MS Excel using a combination of four tables linked through Power Pivot.




Project File:
<a href = "https://github.com/rahat3737/Dowson-Burger-Station-Excel-Dashboard/blob/main/Dowson%20Burger%20Station.xlsx">Dataset View</a>\
The above link will direct viewer the original dataset, where I worked and visualize my dashboard.<br>
I also attached the 'EXECUTIVE SUMMARY' of the analyzed data on this repository.

The aim of this project is to show how Power Pivot is used to perform calculations when working with two or more tables. It can also build calculations across related tables. Combined with PivotTables, it allows the data to be segmented and calculated accurately.



By using power pivot, I linked 4 table to make calculation among the tables

The key insights of the dashboard are:
- Margin(%) per burger
- Selling quantity per day.
- Segment-wise preference.
- Area-wise preference.
- Size preference.
- Payment method selection, and so on.<br>
